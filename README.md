# 中国象棋 · 楚河汉界

一个**单文件**的中国象棋网页游戏：整个游戏就是一个 `index.html`，不依赖任何图片、音频、字体或第三方库，双击即可在电脑、平板、手机的浏览器里运行。

## 特性

### 两种对战模式
- **人机对战**：四档棋力（入门 / 业余 / 高手 / 大师），可选执红先行或执黑后行（执黑时棋盘自动翻转）
- **双人对战**：同屏轮流走子，适合两个人用一台平板下棋

### 对面坐着的棋手
人机模式下，棋盘对面坐着一位用 SVG 手绘的棋手，旁边放着一杯冒热气的茶：

- 会呼吸起伏、随机眨眼（偶尔连眨两下）
- 轮到他走子时**歪头、眯眼、抬手托腮**，头顶冒出思考气泡
- 落子前身体前倾伸手
- 吃掉你的子会咧嘴笑，被你吃子或被将军会皱眉冒汗
- 开局、吃子、将军、长考、认输都有多套台词
- **四档难度是四个不同的人**：年轻棋童、中年老李、留须高手、戴眼镜的白发老人，袍色、发色、胡须、眼镜各不相同

### 画面
- 棋盘用 CSS `perspective` + `rotateX` 做成俯视 3D 视角，盘体用叠加阴影堆出五层木料厚度
- 棋子是立体圆柱：顶面高光渐变、内圈刻槽、侧壁多层实色阴影，字做阴刻效果
- 木纹与噪点贴图全部由代码在运行时生成，不含任何图片文件
- 棋盘线条用 SVG + `non-scaling-stroke`，任意尺寸都保持锐利；楚河汉界、九宫斜线、兵炮位星点均按传统规制绘制

### 音效与动画
- 所有声音由 **WebAudio 实时合成**，没有一个音频文件：木子落盘的「啪」、吃子的脆响、将军的双音钟鸣、胜利的五声音阶上行、失败的下行、违规走子的闷响
- 棋子抬起 → 平移 → 落下的三段弧线运镜
- 吃子时火花粒子爆开 + 棋盘震动，被吃子旋转缩放消失
- 选中棋子金色脉冲光环，可落点绿色呼吸圆点，可吃点红色脉冲环
- 「将 军」大字弹出 + 红光闪屏，被将一方的将帅持续红光脉冲

### 其他
- 标准中文记谱棋谱（炮二平五 / 馬8进7，含前后马的「前」「后」前缀）
- 双方计时、吃子陈列盘
- 悔棋（人机模式自动退两步，**输了也能悔棋继续下**）
- 提示（引擎算出一步好棋并高亮）
- 棋盘翻转、音效开关、设置本地记忆
- 键盘快捷键：`U` 悔棋 · `H` 提示 · `N` 新局 · `Esc` 关闭弹窗

## 怎么玩

1. 下载 `index.html`，双击用浏览器打开（或访问上方在线地址）
2. 在开始菜单选择模式、棋力、执子颜色
3. **点一下自己的棋子选中**，棋盘上会亮起可走的点，**再点亮点落子**
4. 支持鼠标点击和触屏点按，电脑、iPad、手机都能玩

## 技术说明

### AI 引擎
- Alpha-Beta 剪枝 + 迭代加深 + 置换表（Zobrist 哈希）+ 静态搜索（quiescence）+ 杀手着法 / 历史启发
- 跑在 **Web Worker** 里，所以 AI 思考时界面不卡顿
- 实测深度 5 约 12 万节点 / 1.2 秒
- 低档位会故意加入随机失误，不至于一上来就被虐
- Worker 创建失败时自动降级到主线程搜索（并限制思考时间）

### 规则正确性
用象棋标准 perft 序列校验，三层全部精确吻合：

| 深度 | 着法数 | 标准值 |
|-----|-------|-------|
| 1 | 44 | 44 |
| 2 | 1920 | 1920 |
| 3 | 79666 | 79666 |

另外单独验证了：绝杀判定、困毙、白脸将（对脸）禁止、炮翻山打子、马别腿、象眼与象不过河、兵过河后横走、长将与自然限着和棋。

### 代码结构
整个游戏在一个 HTML 文件里，分为几块：

- `<style>` — 全部样式，含木质材质、3D 棋盘、棋子质感、响应式布局
- `<svg id="avatar">` — 对面棋手的形象
- `<script id="engineSrc">` — 象棋引擎（规则 + 搜索 + 中文记谱），**主线程和 Web Worker 共用同一份源码**
- 主脚本 — 音效合成、棋盘绘制、动画、棋手行为、对局流程
